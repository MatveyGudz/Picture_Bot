# Picture_Bot
Telegram-бот на C++, построенный с использованием библиотеки TgBot, который позволяет пользователям загружать изображения, добавлять к ним теги и просматривать случайные изображения из коллекции без использования баз данных и внешних хранилищ.

Функционал:
загрузка изображений через Telegram;
добавление тегов к изображениям;
получение случайного изображения;
отображение тегов вместе с изображением;
запись комментариев к изображениям;
просмотр комментариев под изображением;

Список команд:
/start - Запуск + показ инструкции
/upload - Загрузить изображение (теги прописываются через пробел)
/getpicture - Получить случайное изображение из загруженных всеми пользователями
/help - Список доступных комманд
